# GAIA Grow, Global и Ocean: запуск и подключения

Актуально на 10 ноября 2026 года. Это инструкция для проекта в `D:\GAIA`. Рабочая учётная запись: **SENQwir**, `gulnarapulatova9@gmail.com`, роль главного администратора. Пароль не изменён. При регистрации и каждом новом входе требуется код из письма.

## 1. Сначала настройте отправку писем

Откройте PowerShell и файл настроек:

```powershell
cd D:\GAIA
notepad .env
```

Файл уже существует; недостающие поля добавлены. **Не заменяйте его целиком содержимым `.env.example`**: так можно потерять свои настройки. Заполняйте существующие строки, не создавая дубликатов.

Для Gmail пример настроек выглядит так:

```dotenv
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURITY=starttls
SMTP_USERNAME=ваш_адрес@gmail.com
SMTP_PASSWORD=пароль_приложения_без_пробелов
SMTP_FROM=ваш_адрес@gmail.com
```

Включите двухэтапную проверку Google и создайте пароль приложения для GAIA в [аккаунте Google](https://myaccount.google.com/apppasswords). Обычный пароль Google здесь не используется. Пароли приложений доступны не для всех типов аккаунтов; если пункта нет, используйте другой SMTP-сервис с разрешённой отправкой. Условия: [справка Google](https://support.google.com/accounts/answer/185833). Для другого провайдера возьмите его hostname, порт, логин и пароль. Поддержаны `starttls` и `ssl`; типичный SSL-порт — 465.

`SMTP_FROM` — отправитель писем, он не обязан совпадать с главным администратором. Получателем кода будет email входящего пользователя. Для своего домена настройте SPF/DKIM у почтового провайдера.

Без работающего SMTP приложение **не выдаёт сессию** и сообщает о проблеме доставки. Это относится и к SENQwir: прежний пароль сохранён, но его одного теперь недостаточно.

## 2. Запустите проект

```powershell
cd D:\GAIA
.\scripts\dev.ps1 -UseSqlite
```

Если PowerShell запрещает запуск сценария, разрешите его только в текущем окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\dev.ps1 -UseSqlite
```

Скрипт устанавливает зависимости, применяет миграции и запускает API и сайт. Оставьте терминал открытым и перейдите на [сайт](http://localhost:5173). Введите **SENQwir** или email, прежний пароль, затем шестизначный код из письма. Код действует 10 минут, используется один раз; после 5 неверных попыток нужно войти заново. Повторная отправка доступна через минуту.

`-UseSqlite` выбирает вашу существующую базу `data/gaia.db`. `.env` может указывать на отдельный PostgreSQL: это другая база. Не меняйте `DATABASE_URL`, если хотите использовать сохранённый локальный аккаунт.

Остановка: **Ctrl+C** в терминале. После изменения `.env` остановите и запустите проект снова. Закрытие вкладки браузера не останавливает сервер.

Альтернатива с Docker Desktop: `docker compose up --build`; остановка — `Ctrl+C`, затем `docker compose down`. Compose использует отдельный PostgreSQL и не переносит аккаунты из локального SQLite. Переменные SMTP/API передаются только контейнеру API; JSON-ключ GEE берётся из `secrets/earth-engine.json`, модели — из `data/models/`. В контейнере путь GEE переопределён на `/workspace/secrets/earth-engine.json`. Docker-запуск этой версии отдельно не проверялся; проверен основной запуск Windows/SQLite.

## 3. Где вводить API-ключи

Все секреты вводятся **только в `D:\GAIA\.env`**. Не размещайте их в `apps/web`, переменных `VITE_*`, скриншотах, Git или сообщениях чата. `.env` и `secrets/` исключены из Git. В Global → **Подключения и API** главный администратор видит названия необходимых полей и факт настройки; сами ключи браузеру не выдаются.

### ИИ-помощник и голос

Создайте ключ на [странице OpenAI API](https://platform.openai.com/api-keys) и обеспечьте доступ аккаунта к выбранным моделям:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_TEXT_MODEL=gpt-4.1-mini
OPENAI_TRANSCRIBE_MODEL=gpt-transcribe
OPENAI_SPEECH_MODEL=gpt-4o-mini-tts
OPENAI_VOICE=coral
```

Кнопка **ИИ-помощник** есть в Grow и Global/Ocean. Напишите вопрос или нажмите **Голосовой ввод**, разрешите микрофон и завершите запись. Распознанный текст попадёт в поле вопроса; отправка — отдельной кнопкой. Максимальная запись 60 секунд/8 МБ. **Озвучить** создаёт голосовой ответ через API, **Остановить звук** прекращает воспроизведение.

Микрофон браузера требует HTTPS либо localhost. В OpenAI отправляются вопрос, последние сообщения диалога и выбранные показатели/координаты; ключ остаётся на сервере. Применён `store=false` для Responses API, но это не отменяет правила обработки данных самим провайдером. Помощник не управляет оборудованием. Лимит приложения: 30 текстовых и 30 голосовых запросов на аккаунт в час. Существуют также квоты и тарификация OpenAI. [Текстовый API](https://developers.openai.com/api/docs/guides/text), [распознавание](https://developers.openai.com/api/docs/guides/speech-to-text), [синтез речи](https://developers.openai.com/api/docs/guides/text-to-speech).

### Copernicus / Sentinel-2

1. Зарегистрируйтесь в [Copernicus Data Space](https://dataspace.copernicus.eu/).
2. Откройте [Sentinel Hub Dashboard](https://shapps.dataspace.copernicus.eu/dashboard/), User settings → OAuth clients.
3. Создайте серверный OAuth-клиент и скопируйте client ID и secret:

```dotenv
COPERNICUS_CLIENT_ID=идентификатор_клиента
COPERNICUS_CLIENT_SECRET=секрет_клиента
```

4. Перезапустите GAIA. В анализе территории включите **Индексы Sentinel-2**, выберите период и радиус до 50 км.
5. **Получить снимок выбранной области** выполняет обработку мозаики в естественных цветах через Process API. Кнопка использует текущие параметры формы, а не параметры ранее сохранённого анализа.

Каталог реальных сцен STAC доступен без этих ключей. Ключи нужны для численной обработки и отдельного изображения области. Учётные данные, права и квота должны быть действительны; присутствие строки в `.env` этого не доказывает. [OAuth](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Overview/Authentication.html), [Statistics](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Statistical.html), [квоты](https://documentation.dataspace.copernicus.eu/Quotas.html).

### NASA Earthdata и FIRMS

NASA GIBS (изображения), CMR (каталог), EONET (события) и GISTEMP (климат) используются без ключа. Для авторизованного доступа к поддерживаемым данным создайте аккаунт [Earthdata Login](https://urs.earthdata.nasa.gov/) и пользовательский токен:

```dotenv
EARTHDATA_TOKEN=токен_Earthdata
```

Токен передаётся только сервером NASA CMR. Текущая версия получает метаданные гранул MOD09GA и ссылки на продукты; универсальная загрузка и расчёт произвольных HDF/NetCDF-файлов NASA здесь не реализованы. Для просмотра спутникового изображения токен не нужен.

Для отдельных координат тепловых аномалий запросите MAP_KEY на [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/api/):

```dotenv
FIRMS_MAP_KEY=ваш_map_key
```

После перезапуска откройте **Изменения и события → Очаги FIRMS за сутки**. Без этого ключа по-прежнему доступны события EONET и тепловые слои GIBS. Тепловая аномалия не обязательно является лесным пожаром.

### Google Earth Engine

1. Создайте Google Cloud project, включите Earth Engine API и зарегистрируйте проект для подходящего коммерческого или некоммерческого режима.
2. Создайте сервисный аккаунт и выдайте необходимые права на вычисления Earth Engine и использование проекта. Следуйте [официальной инструкции](https://developers.google.com/earth-engine/guides/service_account); обычного API-key Google Maps недостаточно.
3. Скачайте JSON-ключ сервисного аккаунта и сохраните локально в `D:\GAIA\secrets\earth-engine.json`. Не добавляйте файл в репозиторий.
4. Заполните:

```dotenv
GEE_PROJECT=ваш_project_id
GEE_SERVICE_ACCOUNT=имя@ваш_project_id.iam.gserviceaccount.com
GEE_KEY_FILE=D:/GAIA/secrets/earth-engine.json
```

5. Перезапустите сервер. Для территории включите **Архивный анализ Earth Engine**. Global вычисляет потери древесного покрова UMD Hansen 2001–2025; Ocean — историю водной поверхности JRC 2012–2021. В разделе событий можно включить карту потерь древесного покрова.

Обработка ограничена радиусом 50 км и числом пикселей. Ряды привязаны к опубликованным версиям: результаты 2021/2025 годов не выдаются за измерение сегодня. Для нового продукта потребуются обновление адаптера и повторная проверка.

### Open-Meteo

Без ключа используются открытые погодный, атмосферный и морской API в пределах условий бесплатного некоммерческого доступа. Для коммерческой нагрузки приобретите соответствующую подписку и заполните `OPENMETEO_API_KEY`; сервер переключится на customer endpoints. [Условия и тарифы](https://open-meteo.com/en/pricing).

## 4. Как работать

- **Grow**: создайте участок, зоны и растения; зарегистрируйте прибор, получите ключ устройства и отправляйте телеметрию. Мониторинг отдельно показывает полевые показания и ближайшие ячейки погодных моделей. До поступления телеметрии локальная влажность/pH неизвестны. Сохранены заметки и фото, добавлены спутниковая карта, внешние условия, экспорт и помощник.
- **Global → Обзор планеты**: спутниковая карта, временные слои, климатические ряды, природные события и краткая сводка Ocean. Каждое значение имеет собственную дату наблюдения.
- **Территории**: выберите координаты/круг и даты, запустите анализ. Источники запрашиваются независимо: сбой одного не превращается в выдуманное значение другого. Результаты сохраняются, доступны через URL и экспорт JSON.
- **Ocean**: морские условия, водные спектральные индексы, архив площади водоёмов и отдельная секция модели риска микропластика.
- **Изменения и события**: события NASA, фильтры, FIRMS, карта потерь древесного покрова при подключённом GEE.
- **Организации**: публичный справочник, не заявление о партнёрстве с GAIA. Метки обозначают города размещения.
- **Управление доступом**: SENQwir назначает/отзывает администраторов среди зарегистрированных аккаунтов. Обычный администратор не управляет ролями и не получает доступ к чужим участкам Grow.

Старые сгенерированные измерения сохранены в базе как архив, но исключены из рабочих экранов. Фоновая генерация и команды виртуального полива отключены. Драйвер физического насоса или видеопоток камеры нельзя заменить изменением надписи в интерфейсе: их нужно подключать к конкретному оборудованию.

## 5. Проверки и устранение проблем

```powershell
cd D:\GAIA
$env:DATABASE_URL = "sqlite:///D:/GAIA/data/gaia.db"
.\scripts\check.ps1
.\.venv\Scripts\python.exe scripts/probe_earth_sources.py
```

Браузерные проверки: `cd apps\web`, затем `npm run test:e2e`. Они используют отдельную БД, тестовый почтовый ящик и явно записанные ответы открытых API; эти механизмы не включаются в рабочем сервере.

- Письмо не пришло: проверьте отправителя, пароль приложения/SMTP, порт, папку «Спам», лимиты отправки. Секреты в сообщении об ошибке не печатаются.
- 401/403 у источника: неверный ключ или недостаточные права. 429: квота. 502/503: источник/подключение недоступны. Ответы внешних сервисов с секретами пользователю не передаются.
- Пустой снимок: проверьте период слоя, облачность, орбитальные пробелы и масштаб. Выбор слоя подставляет последнюю дату его каталога; она может быть архивной.
- Нет численной оценки: проверьте доступ и наличие данных. Универсальный «балл здоровья планеты» без валидированной модели не рассчитывается.
- Обучение моделей: [полная инструкция](model-training.md). Научные ограничения и происхождение данных: [описание методов](earth-data-methods.md).

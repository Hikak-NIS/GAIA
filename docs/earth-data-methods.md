# Источники, методы и границы интерпретации GAIA

Текущая реализация — 10 ноября 2026 года. [Запуск и ключи](real-data-setup.md) · [Обучение](model-training.md) · [Проверки](earth-verification.md).

## Что означает «реальные данные»

Каждый показатель хранит значение либо `null`, единицы, источник, дату наблюдения, метод и историю. Различаются полевой прибор, спутниковый продукт, расчётная модель и наблюдательный климатический ряд. Дата получения ответа не заменяет дату измерения. При сбое источника сохраняется сообщение о недоступности, без синтетической подстановки. Отсутствие данных не означает хорошее экологическое состояние.

Глобальный экран объединяет опубликованные продукты. Он не выполняет одномоментное измерение всей Земли и не усредняет несколько выбранных точек в показатель планеты.

## Карта и глобальные ряды

| Источник | Реализовано | Ограничения |
|---|---|---|
| [NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/access-basics/) | Каталог WMTS; естественные цвета MODIS, NDVI, аэрозоли, тепловые аномалии, хлорофилл-а, температура моря и её аномалия, снег и лёд | 10 доступных слоёв при проверке; каталог определяет актуальную дату, периодичность, масштаб и легенду. Изображение не является численным анализом области |
| [NASA GISTEMP v4](https://data.giss.nasa.gov/gistemp/) | Месячная глобальная аномалия температуры суши и океана; последние 600 месяцев | Норма 1951–1980, не доиндустриальная. Новые месяцы появляются с задержкой |
| [NOAA GML](https://gml.noaa.gov/ccgg/trends/gl_data.html) | Глобальная среднемесячная концентрация CO₂, ppm; последние 600 месяцев | Предварительные месяцы могут пересматриваться. Не локальная концентрация на участке |
| [NSIDC Sea Ice Index v4](https://nsidc.org/data/g02135/versions/4) | Суточная протяжённость морского льда обоих полушарий, 10-летняя история и PNG-карты концентрации в полярной проекции | Extent — площадь ячеек с концентрацией ≥15%; не масса льда. Строки с пропусками исключаются. Для трендов нужно учитывать сезонность и предпочтительно месячные агрегаты |
| [NASA EONET v3](https://eonet.gsfc.nasa.gov/docs/v3) | Открытые события за последние 30 дней, до 500 записей; категории, последняя координата, дата и источники | Не исчерпывающий реестр каждого пожара/стихийного явления |
| [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/api/) | VIIRS SNPP за последние сутки, координаты и confidence; полный счётчик, до 3000 меток на карте | Требуется MAP_KEY; термоаномалия не всегда лесной пожар, облака и орбиты оставляют пропуски |

Карта Web Mercator ограничена ±85°. Отдельные изображения NSIDC охватывают полюса. Выбор слоя устанавливает последнюю дату его каталога. Анимация учитывает месячный интервал `P1M`; остальные выбранные продукты перелистываются по дням. Сравнение дат — визуальное, без автоматического расчёта площади изменений.

На проверке 10.11.2026 NASA GISTEMP содержал сентябрь 2026, NOAA CO₂ — июль 2026, NSIDC — 08.11.2026. Один слой морского льда GIBS заканчивался 01.09.2025; это архив, и интерфейс показывает его реальную дату.

Данные Sea Ice Index: Fetterer et al., 2025, Version 4, [DOI 10.7265/a98x-0f50](https://doi.org/10.7265/a98x-0f50). Используются суточные ряды северного/южного полушарий и карты концентрации; дата обращения 10.11.2026. Изображения содержат легенду и атрибуцию NSIDC.

## Анализ территории

Выбор — центр и круг радиусом до 50 км; период спутников до 366 дней. Система сохраняет результат каждого запуска, координаты, даты, ответы источников, показатели и объяснения. Старый анализ остаётся снимком данных на момент запроса. Для новой даты или области нужен новый запуск.

| Источник | Расчёт | Пространственный и временной смысл |
|---|---|---|
| [Open-Meteo Weather](https://open-meteo.com/en/docs) | Температура воздуха, осадки, влажность/температура верхней почвы, ET₀ | Ближайшая модельная ячейка к центру, последние 7 дней до текущего времени. Влажность 0–1 см не заменяет измерение корневой зоны |
| [Open-Meteo / CAMS](https://open-meteo.com/en/docs/air-quality-api) | PM₂.₅, PM₁₀, NO₂, O₃ | Модель атмосферы, не отдельная станция. Не вывод о соблюдении санитарных нормативов |
| [Open-Meteo Marine](https://open-meteo.com/en/docs/marine-weather-api) | Температура поверхности моря, высота волн и скорость течения | Ближайшая морская ячейка, не измерение пресного озера и не среднее всей области |
| [Copernicus STAC](https://documentation.dataspace.copernicus.eu/APIs/STAC.html) | До 12 реальных сцен Sentinel‑2 L2A: ID, время, облачность, геометрия, ссылки/миниатюры при наличии | По ограничивающему прямоугольнику; наличие сцены не гарантирует безоблачность выбранного круга |
| [NASA CMR](https://cmr.earthdata.nasa.gov/search/site/docs/search/api.html) | До 8 гранул MOD09GA.061 с метаданными и ссылками | Это каталог; универсального чтения произвольных HDF/NetCDF в проекте нет |

Рабочие рекомендации опираются на условия в коде и явно показывают основание. Они предлагают полевую проверку, а не объявляют точный диагноз. Универсальный GEHI/балл здоровья Земли для текущего режима не рассчитывается.

## Copernicus Sentinel Hub

После настройки OAuth сервер обращается к Statistical API и Process API Copernicus Data Space. Ключи не отправляются в браузер. Обработка использует L2A, круговую геометрию, фильтр облачности сцен 40%, выбор leastCC. Круг приближён 64 сторонами; пересечение края долготы/полярной границы отклоняется.

Статистика: сетка 256×256, интервалы по 10 дней. В маске исключаются отсутствие данных, дефектные пиксели, облака, тени и снег по SCL. Для суши исключается вода; для Ocean используются только пиксели SCL=6. Это консервативная маска, которая может пропускать сложные прибрежные воды. Сохраняется доля валидных пикселей; полностью пустой интервал не превращается в ноль.

- NDVI = (B08 − B04) / (B08 + B04): растительность.
- NDMI = (B08 − B11) / (B08 + B11): спектральная влага растительности.
- NBR = (B08 − B12) / (B08 + B12): состояние покрова; одного значения недостаточно для установления пожара.
- NDWI = (B03 − B08) / (B03 + B08): водный индекс.
- NDCI = (B05 − B04) / (B05 + B04): индикатор содержания пигментов; не готовая концентрация хлорофилла.
- B04: красная отражательная способность для исследования взвеси. NTU/мг/л требуют локальной калибровки с пробами, поправок на атмосферу, дно, блики и тип воды.

Снимок Process API — 512×512, мозаика естественных цветов за выбранный период. Это не изображение с гарантированным разрешением 10 м: фактический размер пикселя зависит от области. Статистические индексы вычисляются отдельно. [Описание Statistical API](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Statistical.html).

## Earth Engine и изменения экосистем

Сервисный аккаунт и зарегистрированный Cloud project обязательны. Численный анализ ограничен 50 км, 30 м и 40 млн пикселей.

- Леса: `UMD/hansen/global_forest_change_2025_v1_13`, потери 2001–2025, исходный древесный покров ≥30% в 2000 году. Ежегодная площадь в км². Потеря покрова не равна незаконной вырубке; причины могут включать пожары. Карта показывает год потери. [UMD Hansen v1.13](https://storage.googleapis.com/earthenginepartners-hansen/GFC-2025-v1.13/download.html).
- Водоёмы: `JRC/GSW1_4/YearlyHistory`, площадь сезонной и постоянной воды в круге за 2012–2021. Это явно архивный продукт; выбранный в форме текущий месяц не меняет годы этого ряда. [JRC Global Surface Water](https://global-surface-water.appspot.com/download).

Для ледников сейчас доступны снимки/снежный покров и полярные продукты морского льда. Численный баланс массы ледников, универсальная химия почв, вся биота и юридическая классификация повреждённых земель не реализуются из этих источников автоматически. Для них нужны отдельные согласованные продукты и валидация.

## Ocean и модели риска

Начальный экран показывает морскую модель в трёх подписанных точках Атлантического, Тихого и Индийского океанов; это не среднее мирового океана. Спутниковый хлорофилл-а доступен на карте NASA, местные спектральные индикаторы — через Sentinel‑2, история площади воды — через GEE.

Микропластик напрямую спутником не измеряется. Подготовлен обучаемый классификатор риска на признаках загрязняющей нагрузки, стока, населения и течений. Нужны совместимые лабораторные пробы и независимая проверка. Модель не поставляется с вымышленными обученными весами. Подробности — [обучение](model-training.md).

## Реализация и эксплуатация

Основной API: `apps/api/gaia/api/routes/earth.py`; адаптеры: `services/{earth_sources,planet,environment,copernicus_live,gee_live,earth_analysis}.py`. Фронтенд: `apps/web/src/earth/`. Модели обучения: `scripts/train_eco_model.py`, `services/eco_model.py`.

Запросы к независимым источникам выполняются параллельно, с тайм-аутами и ограниченным TTL-кэшем. Разовый отказ сохраняет доступ к остальным результатам. Для аналитики, помощника, голоса и отдельных изображений действуют серверные квоты на аккаунт. Для масштабирования нужны общий кэш, очередь тяжёлых вычислений и эксплуатационный мониторинг; текущий запуск — один API worker.

Глобальные маршруты проверяют роль администратора. Grow проверяет владение участком. ИИ получает только разрешённый пользователю контекст; он не управляет приборами. Подтверждение почты требуется перед выдачей сессии; коды ограничены сроком, числом попыток и повторной отправкой. Главный администратор видит названия настроек и статус наличия, но не значения секретов.

Справочник организаций содержит четыре реальные организации с официальными ссылками. Маркеры обозначают города размещения; статус партнёра GAIA не заявляется. Справочник не является полной базой всех экологических организаций мира.

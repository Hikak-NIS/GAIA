# Обучение моделей GAIA

В проекте реализованы обучение и выполнение двух исследовательских моделей: риск деградации суши и риск микропластика. **Обученные на реальных полевых данных веса пока не поставляются:** у проекта нет вашей размеченной выборки. Тестовая выборка проверяет только программный процесс и не устанавливается как рабочая модель.

ИИ-помощник OpenAI и эти модели — разные компоненты. API-ключ даёт доступ к помощнику; он не обучает экологическую модель и не превращает спутниковые индексы в подтверждённый диагноз.

## 1. Определите целевую задачу

Выберите регион, биом/тип водоёма, сезон, масштаб, горизонт прогноза и единое определение целевого класса `risk_label`:

- `0` — отрицательный класс по вашей утверждённой методике;
- `1` — положительный класс по той же методике.

Для суши метку должен подтверждать обследователь: например, заранее заданная степень нарушения покрова/эрозии. Для микропластика метка выводится из сопоставимых лабораторных проб и явно заданного исследовательского критерия. Универсального порога концентрации код не задаёт. Полное определение указывается через `--label-definition` и сохраняется с моделью.

Не используйте в качестве целевой метки «оценку ИИ» или GEHI, вычисленный из тех же входных признаков: это воспроизведёт формулу, а не проверит экологическое состояние.

## 2. Соберите данные

Каждая строка должна иметь `site_id` (устойчивый ID площадки/станции), `observed_at` (ISO-дата отбора пробы/обследования), `risk_label` и все численные признаки. Сохраняйте отдельно координаты, глубину, единицы, методы, протоколы контроля качества, источник, разрешение и даты спутниковых сцен. Объединение разных методик требует согласованной калибровки.

Шаблоны заголовков: [суша](templates/land-training.csv), [микропластик](templates/microplastics-training.csv). Они не содержат выдуманных измерений.

### Признаки суши

| Поле | Единицы и определение |
|---|---|
| `ndvi` | безразмерный индекс, обычно −1…1; агрегат по площадке, согласованное окно относительно обследования |
| `ndmi` | безразмерный индекс влаги растительности −1…1 |
| `soil_moisture` | м³/м³; зафиксировать глубину и метод, не смешивать с процентами датчика без преобразования |
| `temperature_anomaly` | °C относительно документированной климатической нормы; не абсолютная температура |
| `rainfall_30d` | мм за 30 дней **до** обследования |
| `tree_loss_fraction` | 0…1, доля площади с потерей покрова за заданный одинаковый период |

### Признаки микропластика

| Поле | Единицы и определение |
|---|---|
| `population_density` | человек/км² в согласованном водосборе или буфере |
| `distance_to_river_km` | км до ближайшей релевантной реки/устья |
| `wastewater_sites_10km` | количество зарегистрированных источников сточных вод в радиусе 10 км |
| `runoff_mm` | мм стока за согласованное предшествующее окно |
| `current_velocity` | м/с; перевести значения API в эти единицы перед обучением |
| `plastic_waste_kg_km2` | кг/км² за один и тот же временной период, с документированным источником |

Начальный источник полевых проб — [NOAA NCEI Marine Microplastics](https://www.ncei.noaa.gov/products/microplastics). Портал позволяет выгружать CSV/JSON/GeoJSON. Методы и концентрации разных исследований не всегда сопоставимы: сначала изучите метаданные, размеры частиц, сетки отбора и единицы. Сам архив не содержит автоматически все перечисленные признаки загрязняющей нагрузки; их нужно собрать и пространственно/временно сопоставить отдельно.

Мутность и хлорофилл: собирайте синхронные пробы NTU, взвешенных частиц мг/л, хлорофилла-а мкг/л и спектральные признаки. Текущий классификатор риска не является регрессионной моделью этих концентраций. Для такой задачи нужен отдельный датасет и проверка регрессии.

## 3. Подготовьте CSV

Сохраните реальные данные, например, в `D:\GAIA\data\training\land.csv`. Эта папка исключена из Git.

- Числа используют точку как десятичный разделитель; разделитель столбцов — запятая.
- Не оставляйте пустые значения, NaN/Infinity или текст вместо чисел. Исправьте или исключите строки с документированным правилом, не заполняйте их произвольными средними.
- Минимум скрипта — 100 строк и 10 различных площадок. Это техническая нижняя граница, **не доказательство достаточного объёма**. Для устойчивости обычно нужен существенно больший и репрезентативный набор.
- Должны присутствовать оба класса в обучении и проверке, несколько дат и разные площадки.
- Не включайте признаки, появившиеся после целевого события. Удалите дубликаты проб и убедитесь, что соседние/связанные площадки сгруппированы корректно.

## 4. Запустите обучение

Зависимости включены в `apps/api/requirements.lock`; `dev.ps1` устанавливает их. При отдельном запуске:

```powershell
cd D:\GAIA
.\.venv\Scripts\python.exe -m pip install -r apps/api/requirements.lock
.\.venv\Scripts\python.exe scripts/train_eco_model.py --data data/training/land.csv --kind land --label-definition "Ваша документированная полевая методика класса 1" --output data/models/land-risk.json
```

Для микропластика:

```powershell
.\.venv\Scripts\python.exe scripts/train_eco_model.py --data data/training/microplastics.csv --kind microplastics --label-definition "Ваш критерий класса риска по лабораторным пробам" --output data/models/microplastics-risk.json
```

Модель — Random Forest, 120 деревьев, ограничение глубины 8, минимум 4 наблюдения в листе. Артефакт записывается в **JSON**, не pickle. Перед существующим файлом скрипт останавливается: выбирайте новый путь для очередного эксперимента и сохраняйте версии.

## 5. Проверьте отчёт перед использованием

Скрипт резервирует около 20% площадок и использует более поздние даты для проверки. Обучение идёт на других площадках до временной границы. Остальные строки исключаются из этой проверки; их число указано в отчёте. Если после разделения данных/классов недостаточно, обучение прекращается.

Рядом появится `land-risk.report.json` или `microplastics-risk.report.json` с:

- SHA-256 исходного CSV, датой обучения, размером и составом отложенной выборки;
- ROC-AUC, average precision, Brier score и balanced accuracy при пороге 0,5;
- важностью признаков и определением класса.

Метрики не обеспечивают автоматическое разрешение на использование. Сравните модель с базовым прогнозом частоты класса, изучите ошибки по сезонам/регионам, оцените интервалы неопределённости и калибровку на независимых данных. Встроенный порог 0,5 — технический, а не экологический норматив. Настройку гиперпараметров проводите на отдельной валидационной выборке, не многократно подгоняя результаты под финальный тест.

## 6. Используйте проверенную версию

Рабочий сервер читает `data/models/land-risk.json` и `data/models/microplastics-risk.json`. В Global/Ocean соответствующий раздел показывает отчёт и форму ввода признаков. Автоматического подключения произвольных колонок CSV к живым API нет: требуется совпадение единиц, временных окон и пространственного масштаба.

Результат — вероятность заданного класса риска. Это не измерение концентрации микропластика и не универсальный балл экосистемы. Признаки за пределами диапазонов обучения отклоняются. Этот контроль не выявляет все случаи сдвига распределения; географическая переносимость требует отдельной проверки.

API: `GET /api/v1/earth/models`, `POST /api/v1/earth/models/predict` с `kind` и `features`. Доступ только администраторам. Для нормальной работы нужны ваши реальные данные, описание целевой метки и оценка качества специалистом; готовые научно проверенные веса без них создать нельзя.

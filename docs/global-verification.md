# GAIA Global: результаты проверки

Дата завершения: **9 ноября 2026 года**, Asia/Qyzylorda.

## Что работает

- Отдельное пространство `/global` с серверным доступом только для `admin` и `superadmin`.
- Обязательный уникальный ник при регистрации; вход по нику или email. Старые аккаунты сохраняют возможность входа по email и смены технического ника в профиле.
- Главный администратор ищет зарегистрированные аккаунты и назначает либо отзывает роль администратора. Смена ролей журналируется; отозванная роль блокирует следующие запросы даже в действующей сессии.
- Карта, координаты, регионы-примеры, радиус области, ручные маркеры, OpenStreetMap и визуальная подложка NASA GIBS.
- Семь DEMO-показателей, GEHI с объяснением факторов, редактируемые главным администратором веса, графики из 12 месячных точек и условные стратегии восстановления.
- Сохранение анализов, постоянная ссылка на результат, история и экспорт JSON.
- Отдельные модули Copernicus, NASA Earthdata и Google Earth Engine с явным статусом подключения.

## Ограничения проверки

- Численные показатели, история и рекомендации — **DEMO / SIMULATED DATA**. GEHI — концептуальная модель без научной валидации. GIBS служит только визуальной подложкой.
- Численный импорт из Copernicus, NASA Earthdata и Earth Engine пока не подключён; запросы таких провайдеров возвращают 503. Условия и дальнейшие шаги описаны в [источниках данных](global-data-sources.md).
- PostgreSQL из локального `.env` был недоступен. Для него проверена генерация миграционного SQL; работа с живым PostgreSQL в этой проверке **не подтверждена**. Данные указанного пользователя проверены именно в SQLite.
- В тестовых зависимостях остаются два предупреждения об устаревающих интерфейсах Starlette/httpx/AnyIO. Vite сообщает о размере общего существующего JS-пакета свыше 500 kB; GlobalPage и AccessPage загружаются отдельными пакетами. Это предупреждения, не ошибки проверок.

После проверки серверы на портах **8000, 8001, 5173, 5174** не оставлены запущенными. Запуск и остановка описаны в [инструкции пользователя](global-guide.md).

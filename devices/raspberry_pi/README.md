# Raspberry Pi: подготовленный контракт

1. Войдите в GAIA и на вкладке территории «Настройки» выпустите ключ устройства.
2. Передайте `GAIA_SENSOR_ID`, `GAIA_DEVICE_API_KEY` и при необходимости `GAIA_API_BASE` как переменные среды.
3. Запустите `python client.py`.

Ключ показывается один раз; повторный выпуск отзывает предыдущий. Клиент демонстрирует HTTP-контракт без GPIO. В будущем чтение конкретных датчиков заменит значения `GAIA_SAMPLE_*`, а доменная логика, БД и интерфейс останутся прежними. Не записывайте ключ в исходники или Git.
